# Prototype Policy Documents

These documents separate the policy-like rules currently encoded in L3/L2 from application code so they can be chunked and indexed in ChromaDB. They are derived from the L2 prototype, not approved company policy. `effective_date: unspecified` and `approval_status: unverified` are intentional; do not present these documents as current authoritative company guidance.

Each Markdown section has a stable section ID for citations. An ingestion process should retain the front matter as document metadata and the `##` section heading/ID as chunk metadata. Keep the source implementation references when revising these documents. Replace or approve this corpus with named company-owned documents before using the policy assistant for real employee guidance.
